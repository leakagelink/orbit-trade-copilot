# Timing and rounding policy register — Phase 4H finalization (13 Nov 2026)

Owner decision C: **conservative**. Ambiguous data is refused or paused, never guessed. **Every value below is NOT APPROVED** and stays an engineering value or caller configuration until the owner confirms it individually. Draft 0052 introduces **no new tolerance**; it reuses 0049's 1e-9 comparison and 0051's 1e-9 band.

**Conventions.**
- All times are integer milliseconds since the Unix epoch, UTC.
- *Candle times* come from the exchange kline open time. They are recorded by the worker from public Binance data and are **not independently verified** (G12).
- *Commit-time checks* use the database clock, `clock_timestamp()`, read at the start of the commit.
- "Refused" means the whole candle rolls back and nothing is written. The worker's refusal planner then classifies the message:
  - `futures paper completeness: …` and anything unknown → halt for review (account paused);
  - known fill/approval codes → deterministic recompute;
  - lost reply → resend identical payload once.
